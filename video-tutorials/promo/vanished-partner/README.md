# "השותף שנעלם" — סרטון 7 במסמך הרעיונות

28.5 שניות, אנכי 1080×1920, 30fps. קהל: ספקנים (שבוע 3 בטבלת המעקב). קריינות: Adam על ElevenLabs v3,
כמו בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n5.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs vanished-partner            # -> out/promo/vanished-partner.mp4
node promo/render.mjs vanished-partner --stills --at=5.8,9,11.6,14.4,18.6,22.5,27.5
../../OpenMontage/.venv/Scripts/python.exe promo/vanished-partner/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=11` כדי לעצור על שנייה 11.
