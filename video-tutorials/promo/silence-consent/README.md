# "השקט הוא הסכמה" — סרטון 1 במסמך הרעיונות

23 שניות, אנכי 1080×1920, 30fps. קהל: כללי (שבוע 4 בטבלת המעקב). קריינות: Adam על ElevenLabs v3, כמו
בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n5.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs silence-consent            # -> out/promo/silence-consent.mp4
node promo/render.mjs silence-consent --stills --at=5,9.5,12,16.8,22
../../OpenMontage/.venv/Scripts/python.exe promo/silence-consent/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=12` כדי לעצור על שנייה 12.

## סצנות

| זמן | מה רואים | קריינות |
|---|---|---|
| 0–5.5 | "מה קורה כשאף אחד בקבוצה לא עונה?" בקבוצת "הצוות 🚀" מישהו שואל "מי בעד שנעלה את האתר ביום ראשון?", ההודעה נקראה ע״י 6, הימים עוברים עד "שבוע אחרי", צרצר 🦗, והכול מאפיר. "הכול נתקע." | "מה קורה כשאף אחד בקבוצה לא עונה?" · "בדרך כלל? הכול נתקע." |
| 5.3–17.6 | "ברקמה, לכל הצעה יש שעון": הצעה "להעלות את האתר ביום ראשון" עם זמן תגובה של 48 שעות שרץ לאפס. נועה ועידו מאשרים. "אישור · שיחה · הצעה נגדית" ("הצעה נגדית מחזירה את השעון להתחלה"). מאיה, תום ושירה שותקים, ומסומנים. השעון מגיע ל-0 ועל ההצעה ננחתת חותמת "✓ אושר · השתיקה נספרה כהסכמה". "אף אחד לא היה צריך לרדוף אחרי אף אחד" | "ברקמה, לכל הצעה יש שעון. מי שרוצה לשנות, מגיב. ומי ששותק... מסכים." · "וכשהזמן נגמר, ההצעה מאושרת. לבד." |
| 17.5–23 | 1lev1 · "החלטות שלא נתקעות" · "מי שרוצה לשנות מגיב. מי ששותק מסכים." · 1lev1.com | "אצלנו, החלטות לא נתקעות. אחד-לב-אחד." |

**מול המערכת:** זמן התגובה הוא `restime` של הרקמה, דרך timegrama. הצעה נגדית מאפסת את השעון, ובסוף הזמן
מאושרת הגרסה האחרונה שעל השולחן. 48 שעות הן דוגמה, כי כל רקמה קובעת את הקצב שלה. אין כפתור דחייה,
רק אישור, שיחה או הצעה נגדית.
