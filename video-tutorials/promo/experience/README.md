# "40 שנה של ניסיון. ועכשיו מה?" — סרטון 11 במסמך הרעיונות

27 שניות, אנכי 1080×1920, 30fps. קהל: בעלי ניסיון (שבוע 6 בטבלת המעקב). קריינות: Adam על ElevenLabs v3, כמו
בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n5.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs experience            # -> out/promo/experience.mp4
node promo/render.mjs experience --stills --at=4.1,9.5,16.7,20.3,26
../../OpenMontage/.venv/Scripts/python.exe promo/experience/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=16` כדי לעצור על שנייה 16.
