# "מטיימר לאחוזים" — סרטון 3 במסמך הרעיונות

29.5 שניות, אנכי 1080×1920, 30fps, בלי פרצוף. קהל: כללי (שבוע 2 בטבלת המעקב). קריינות: Adam על
ElevenLabs v3, אותו קול כמו ב-`zero-users` ובמדריך הקונסיירז'. `narrate.py` מייצר את
`assets/narration/n1–n5.mp3`, וכל סצנה מתוזמנת למילים שלה (הזמנים כתובים בהערות ב-`seek`).

```bash
cd video-tutorials
node promo/render.mjs timer-to-equity            # -> out/promo/timer-to-equity.mp4
node promo/render.mjs timer-to-equity --stills --at=3.8,9.5,11.8,15.5,17.6,22.8,28
../../OpenMontage/.venv/Scripts/python.exe promo/timer-to-equity/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=15` כדי לעצור על שנייה 15.

## מוזיקה (לא חובה)

הסרטון עובד עם קריינות בלבד, כמו `zero-users`. כדי להוסיף פסקול שומרים `assets/music.mp3` ומוסיפים
שורה ל-`window.AUDIO` ב-`index.html`, למשל
`{ src: 'assets/music.mp3', in: 0, dur: 29.5, at: 0, vol: .22, fadeIn: .5, fadeOut: 1.5 }`.

> Instrumental, 30 seconds, no vocals. Light modern electronic with a soft ticking clock motif.
> 0–5s: sparse and curious. 5–18s: steady pulse, a sense of work adding up.
> 18–25s: warm chords open up as a number grows. 25–30s: clean resolving hit. ~105 BPM, no drops.
