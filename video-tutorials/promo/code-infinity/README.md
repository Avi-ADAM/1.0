# "הקוד: 3 ערבים. השיווק: ∞" — סרטון 9 במסמך הרעיונות

16.5 שניות, אנכי 1080×1920, 30fps. קהל: ויבקודרים (שבוע 5 בטבלת המעקב). קריינות: Adam על ElevenLabs v3,
כמו בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n4.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs code-infinity            # -> out/promo/code-infinity.mp4
node promo/render.mjs code-infinity --stills --at=3.6,5.2,10.3,15.8
../../OpenMontage/.venv/Scripts/python.exe promo/code-infinity/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=5` כדי לעצור על שנייה 5.
