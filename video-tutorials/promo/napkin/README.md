# "החבר שהפסקת לדבר איתו בגלל כסף" — סרטון 13 במסמך הרעיונות

27 שניות, אנכי 1080×1920, 30fps. קהל: מי שנכווה (שבוע 3 בטבלת המעקב). קריינות: Adam על ElevenLabs v3,
כמו בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n5.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.
כתב היד על המפית הוא Amatic SC מ-Google Fonts (יש בו עברית).

```bash
cd video-tutorials
node promo/render.mjs napkin            # -> out/promo/napkin.mp4
node promo/render.mjs napkin --stills --at=4.5,8.8,15.8,20.3
../../OpenMontage/.venv/Scripts/python.exe promo/napkin/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=8` כדי לעצור על שנייה 8.
