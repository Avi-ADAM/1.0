# "יש לך רעיון? מה הצעד הבא?" — סרטון 14 במסמך הרעיונות

23.5 שניות, אנכי 1080×1920, 30fps. קהל: בעלי רעיון בלי כסף או ידע (שבוע 4 בטבלת המעקב). קריינות: Adam על
ElevenLabs v3, כמו בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n5.mp3`, והזמנים של כל מילה כתובים
בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs next-step            # -> out/promo/next-step.mp4
node promo/render.mjs next-step --stills --at=5.5,15.5,22.5
../../OpenMontage/.venv/Scripts/python.exe promo/next-step/narrate.py --force n1   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=15` כדי לעצור על שנייה 15.
