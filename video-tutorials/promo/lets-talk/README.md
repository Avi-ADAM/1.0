# "אין 'לא', יש 'בוא נדבר'" — סרטון 2 במסמך הרעיונות

24 שניות, אנכי 1080×1920, 30fps. קהל: כללי (שבוע 6 בטבלת המעקב). קריינות: Adam על ElevenLabs v3, כמו בשאר
הסדרה. `narrate.py` מייצר את `assets/narration/n1–n5.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs lets-talk            # -> out/promo/lets-talk.mp4
node promo/render.mjs lets-talk --stills --at=9.5,15.8,23
../../OpenMontage/.venv/Scripts/python.exe promo/lets-talk/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=15` כדי לעצור על שנייה 15.
