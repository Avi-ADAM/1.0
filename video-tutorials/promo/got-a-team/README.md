# "כתבתי מה אני צריך, וקיבלתי צוות" — סרטון 4 במסמך הרעיונות

20.5 שניות, אנכי 1080×1920, 30fps. קהל: לקוחות (שבוע 5 בטבלת המעקב). קריינות: Adam על ElevenLabs v3, כמו
בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n5.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs got-a-team            # -> out/promo/got-a-team.mp4
node promo/render.mjs got-a-team --stills --at=3.2,6.8,12.2,16.2
../../OpenMontage/.venv/Scripts/python.exe promo/got-a-team/narrate.py --force n3   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=12` כדי לעצור על שנייה 12.
