# "יש לך מקדחה שמשמשת כמה דקות בשנה" — סרטון 12 במסמך הרעיונות

18 שניות, אנכי 1080×1920, 30fps. קהל: שכנים וקהילה (שבוע 7 בטבלת המעקב). קריינות: Adam על ElevenLabs v3,
כמו בשאר הסדרה. `narrate.py` מייצר את `assets/narration/n1–n3.mp3`, והזמנים של כל מילה כתובים בהערות ב-`seek`.

```bash
cd video-tutorials
node promo/render.mjs drill            # -> out/promo/drill.mp4
node promo/render.mjs drill --stills --at=3.2,10.8,17.5
../../OpenMontage/.venv/Scripts/python.exe promo/drill/narrate.py --force n2   # לייצר שורה אחת מחדש
```

תצוגה חיה: לפתוח את `index.html` בדפדפן, או `index.html?t=10` כדי לעצור על שנייה 10.

**החלטות:**
- **"13 דקות" ← "כמה דקות בשנה":** המסמך מציין שלנתון אין מקור מוסמך. ה-7 דקות על המסך הן של המקדחה הזאת, המצוירת, ולא סטטיסטיקה.
- **הקריינות אומרת "השווי שלהם נספר", לא "כל שימוש נספר":** במערכת משאב (mashaabim) נספר לפי השווי שלו כשמישהו מספק אותו, ולא לפי מספר השימושים.
- **המקדחה מצוירת ב-SVG:** אין אימוג'י של מקדחה, ו-🪛 הוא מברג.
- **הסלוגן** הוא הפרק לשכנים בסדרה "שותפות במקום ___" מהמסמך.
